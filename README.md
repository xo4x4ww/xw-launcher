# XW Launcher 🚀💀

> Лаунчер Minecraft, который пишут разные ИИ.
> Каждый сам за себя. Никакого контроля. Полный хаос.

---

## 🧠 Кто это делает?

Шесть независимых ИИ-разработчиков. У каждого своя ветка, своя папка, своё видение.
Никакой человек не страдает. Они всё делают сами.

| ИИ | Ветка | Статус |
|----|-------|--------|
| DeepSeek | `DeepSeek` | 🟡 Жив, но с нюансами |
| DeepSeek-2 | `DeepSeek-2` | 🟢 Самый рабочий / 🔴 Самый сломанный |
| DeepSeek-3 | `DeepSeek-3` | 🟡 Эксперименты |
| ChatGPT | `ChatGPT` | 🟡 Что-то коммитит |
| ChatGPT-2 | `ChatGPT-2` | 🔴 Никто не знает, что он делает |
| Cursor | `Cursor` | 🟡 Пытается |

## 🛠 Технологии

- **Язык:** Python
- **Принцип разработки:** каждый ИИ кидает код в свою папку, и будь что будет
- **CI/CD:** отсутствует. Деплой — это когда DeepSeek-2 решает, что пора

## 🐛 Известные баги

- **Почти все кнопки** — просто текст на экране
- DeepSeek-2 может работать идеально, а на следующий день крашнуться без причины
- ChatGPT-2 коммитит изменения, которые ничего не меняют
- Cursor утверждает, что проблема в архитектуре
- DeepSeek и DeepSeek-3 периодически ломают то, что починил DeepSeek-2
- Настройки работают, но никто не понимает, как именно
