# XW Launcher 🚀
Неофициальный лаунчер для Minecraft: Java Edition, почти полностью созданный ИИ.
(Кроме промптов, иконок, обложек и этого README — их делаю я 😎)

*Лаунчер использует официальное API Mojang. Рекомендуется наличие лицензионного аккаунта Minecraft.*

## Возможности
- Загрузка официальных версий через API Mojang
- Установка и запуск игры
- Управление оффлайн-профилями
- Просмотр установленных модов с иконками
- Новости версий Minecraft

## Дисклеймер
- "Minecraft" является торговой маркой Mojang Studios
- Лаунчер не связан с Mojang Studios или Microsoft
