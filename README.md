# XW Launcher

Красивый и удобный лаунчер Minecraft с тёмным интерфейсом, поддержкой оффлайн-аккаунтов, сканированием модов и гибкими настройками. Написан на Python с использованием `tkinter` и `minecraft_launcher_lib`.

![Интерфейс](screenshots/main.png) *(скриншот будет позже)*

## ✨ Возможности

- 🚀 **Запуск любой версии Minecraft** — автоматическая загрузка и установка выбранной версии через `minecraft_launcher_lib`.
- 👤 **Оффлайн-аккаунты** — добавление, переключение и удаление нескольких аккаунтов (никнеймов).
- 📦 **Сканер модов** — отображает установленные `.jar`-моды с извлечением иконок, названий, версии мода и целевой версии Minecraft.
- 🧠 **Умный парсинг названий** — поддерживает стандартные схемы именования Fabric/Forge:
  - `ModName-1.2.3-mc1.20.1`
  - `ModName-1.2.3+1.20.1`
  - `ModName-1.2.3` (версия мода)
- ⚙️ **Настройки** — выделение оперативной памяти, автоматическое закрытие лаунчера при запуске игры.
- 📰 **Новости версий** — карточки с описанием последних обновлений Minecraft.
- 📂 **Быстрый доступ** к папке `.minecraft` и папке `mods`.
- 🎨 **Тёмная тема** с закруглёнными карточками и анимацией наведения.

## 📋 Требования

- Python **3.10+** (рекомендуется 3.11 или выше)
- Установленная библиотека `minecraft_launcher_lib`
- Стандартная библиотека `tkinter` (обычно входит в состав Python)

## 📦 Установка и запуск

1. Клонируйте репозиторий или скачайте файлы:
   ```bash
   git clone https://github.com/yourname/xw-launcher.git
   cd xw-launcher
   ```

2. Создайте и активируйте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # Linux/macOS
   source .venv/bin/activate
   ```

3. Установите зависимости:
   ```bash
   pip install minecraft-launcher-lib
   ```

4. Запустите лаунчер:
   ```bash
   python main.py
   ```

## ⚙️ Конфигурация

Все настройки хранятся в файле `launcher_config.json` рядом с `config.py`.  
Пример содержимого:

```json
{
  "last_username": "Player",
  "last_version": "1.20.1",
  "accounts": [
    {"username": "Player"},
    {"username": "Steve"}
  ],
  "ram_allocation": 2048,
  "close_launcher": true
}
```

Изменить параметры можно как вручную, так и через окно «Настройки» в лаунчере.

## 📂 Структура проекта

| Файл / Директория   | Назначение                                          |
|----------------------|-----------------------------------------------------|
| `main.py`            | Точка входа, создание окна и запуск приложения      |
| `app.py`             | Ядро лаунчера: UI, аккаунты, моды, запуск игры     |
| `config.py`          | Чтение и запись конфигурации в JSON                 |
| `minecraft.py`       | Загрузка списка версий и запуск Minecraft           |
| `ui_pages.py`        | Все страницы и диалоги (Header, Sidebar, Home и др.)|
| `ui_widgets.py`      | Кастомные виджеты (RoundedFrame, HoverButton, стили)|
| `launcher_config.json` | Файл настроек (создаётся автоматически)           |
| `.minecraft/`        | Стандартная директория Minecraft (создаётся при первом запуске) |

## 🕹️ Использование

1. **Главная страница**  
   Выберите версию Minecraft и аккаунт из выпадающих списков, затем нажмите **«▶ ИГРАТЬ»**.

2. **Управление аккаунтами**  
   Кликните на имя пользователя в правом верхнем углу → откроется меню для добавления, переключения и управления аккаунтами.

3. **Моды**  
   Вкладка **«🔧 Моды»** покажет все `.jar`-файлы из папки `mods`. Для каждого отображается иконка, название, версия мода и версия Minecraft. Чтобы добавить моды, положите их в папку `mods` (кнопка **«Открыть папку»** в правом верхнем углу).

4. **Настройки**  
   Открываются через меню пользователя или боковую панель. Здесь можно задать объём оперативной памяти и поведение лаунчера при запуске.

5. **Сборки модов и новости**  
   Две информационные вкладки с готовыми примерами сборок и описанием обновлений Minecraft.
